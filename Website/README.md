# iLand Website

Statische Support- und Datenschutzwebsite ohne JavaScript, Cookies oder Analytics.
Cloudflare Pages veröffentlicht ausschließlich `Website/public`, niemals das Repository-Wurzelverzeichnis.

Lokal: `python3 -m http.server 8080 --directory Website/public`

Git-Integration: privates GitHub-Repository, Branch `main`, Root `Website`, Output `public`, kein Build-Befehl. Keine API-Schlüssel erforderlich.

Live: https://iland-app.pages.dev · Support: /support/ · Datenschutz: /datenschutz/

Cloudflare-Projekt `iland-app`, verbunden mit `TheSocialNetwork35/iLand` (privat). Preview-Deployments sind deaktiviert. Der öffentliche Kontakt entspricht der öffentlich im GitHub-Profil angegebenen Adresse.
